# Transformation Ownership Registry (v1)

## Purpose

Define canonical ownership of every morphological rule.

## Rule Table Schema

| Rule ID \| Source Ending \| Target Ending \| Direction \| Language \|
  Confidence Baseline \| Exception Owner \|

Each rule must: - Have a unique Rule ID - Declare bi-directional or
uni-directional behavior - Declare exception table ownership - Declare
base confidence baseline

## Mutation Policy

Rules may only be modified via formal change protocol. No overlapping
rule definitions allowed.
