# Inference Legality Matrix (v1)

## Purpose

Define when morphological inference is allowed.

| Source POS \| Source Ending \| Target POS \| Allowed \| Conditions \|

Rules: - Verb back-formation must be explicitly allowed. - Reverse
inference must meet frequency threshold. - Cross-family inference
(Romance ↔ Germanic) requires validation.

Illegal inferences must return structured failure.
