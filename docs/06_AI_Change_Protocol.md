# AI Change Protocol (v1)

## Required Before Adding Any Rule

1.  Declare impacted existing rules
2.  Provide corpus validation sample size
3.  Estimate false positive rate
4.  Define exception expectation ratio
5.  Validate reverse inference
6.  Confirm no rule overlap

## Required After Rule Addition

-   Update registry
-   Update legality matrix
-   Provide regression summary
-   Confirm no new mutation surface created
